# Pixel Formula — Telegram Mini App (Fantasy F1)

Telegram Mini App для фэнтези Формулы-1 в пиксельном стиле.

## Стек
- React + TypeScript + Vite
- @tma.js/sdk-react
- React Router

## Запуск
```bash
npm install
npm run dev
```

## Что уже есть
- Пиксельный UI + навигация
- Моковые данные пилотов и календаря
- Выбор команды + система очков
